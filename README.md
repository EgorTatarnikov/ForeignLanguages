# Foreign Languages

В данном репозитории собраны мои проекты, инструменты и материалы для изучения иностранных языков.<br>
В процессе изучения английского языка я выработал собственный подход и разработал свои инструменты.<br>
Буду рад, если эти материалы принесут пользу и другим людям.

## 🎯 Цель репозитория

- Демонстрация проектов и навыков в создании готовых продуктов с использованием разных технологий
- Агрегация инструментов и материалов по изучению языков в одном месте
- Помощь другим людям в изучении иностранных языков

## 📦 Проекты

### <img align="center" src="https://raw.githubusercontent.com/EgorTatarnikov/WordByHeart/main/WordByHeart_v2.svg" width="24" alt="wt badge"> [Word by Heart](https://github.com/EgorTatarnikov/WordByHeart)
Методика изучения английского языка через чтение книг и просмотр сериалов в оригинале.

В основе методики лежит **NLP-программа**, которая:
- анализирует текст
- выбирает **наиболее важные слова**
- переводит лексику **с учётом контекста**
- формирует двусторонние карточки слов для изучения
  
Изучение небольшого количества наиболее важных слов позволяет быстро приступить к чтению и просмотру контента на родном языке.

## 🔗 Полезные ресурсы
- **[lingvolive.com](https://www.lingvolive.com/)** – онлайн словарь с правильным произношением и примерами из текстов
- **[context.reverso.net](https://context.reverso.net/)** – примеры использования слов и фраз в разных источниках с переводом с учетом контекста
- **[forvo.com](https://forvo.com/)** – база аудиофайлов с произношением слов, записанных разными людьми на множестве различных языков мира
- **Murphy Grammar in Use** – отличная серия книг по английской грамматике. Делится на 3 уровня. По моему мнению, синяя (средняя) книга охватывает всё, что нужно для свободного общения и понимания англоязычной информации
